PASSA OU REPASSA — VERSÃO DE TESTE

COMO USAR
1. Abra o arquivo index.html no navegador (Chrome/Edge recomendado).
2. Pressione A para a Equipe Azul ou D para a Equipe Vermelha.
3. A primeira tecla pressionada trava a rodada para o outro time.
4. Use os botões na tela para marcar acerto/erro, mostrar resposta ou avançar.

ATALHOS
A = Equipe Azul
D = Equipe Vermelha
ESPAÇO = iniciar/pausar cronômetro
N = próxima pergunta
R = liberar os botões e reiniciar a disputa da pergunta atual

OBSERVAÇÕES
- As 10 perguntas estão diretamente no arquivo script.js.
- O som é gerado pelo próprio navegador, sem arquivos externos.
- Para publicar depois no Vercel, basta colocar estes arquivos em um projeto estático.
- Um futuro Arduino/ESP32 pode simular as mesmas teclas A e D, sem mudar a lógica principal do site.
